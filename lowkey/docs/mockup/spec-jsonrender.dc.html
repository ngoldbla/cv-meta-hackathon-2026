What the server sends

The card on board 2 is drawn from this json-render spec. Low Key's code builds it from the tool results; the page draws it with a fixed catalog of components. The AI never writes these numbers.

{
  "root": "crv",
  "elements": {
    "crv": {
      "type": "PickCard",
      "props": { "rank": 1, "badge": "best resale",
        "model": "Honda CR-V LX", "inStock": true,
        "sentence": "Keeps about 63% of its price…" },
      "children": ["cost", "life", "water", "dealer"]
    },
    "cost": {
      "type": "CostBars",
      "props": {
        "pay":  [{ "part": "loan", "usd": 577 },
                 { "part": "gas",  "usd": 166 }],
        "real": [{ "part": "valueLost", "usd": 197 },
                 { "part": "interest",  "usd": 97 },
                 { "part": "gas",       "usd": 166 }],
        "backWhenSold": 282
      }
    },
    "life":  { "type": "LifespanTrack",
               "props": { "years": 13.9, "loanYears": 5,
                          "source": "iSeeCars 2026" } },
    "water": { "type": "UnderwaterMini",
               "props": { "evenMonth": 6,
                          "curveRef": "ownership:crv" } },
    "dealer": { "type": "DealerLine",
               "props": { "miles": 13.7, "year": 2026,
                          "price": 31950, "more": 2 } }
  }
}
The catalog CostCompare: one bar per pick, segmented, shared scale CostBars: "you pay" vs "really costs", gap = back when sold LifespanTrack: 0–20 years, loan years marked UnderwaterMini: the task-026 mini chart DealerLine: cheapest unit + "N more nearby" Every number is checked against the tool results before it is sent.
